# Итоговые модели

`jepa-models-2026-09-28/` — пакет итогового каскада: YOLO26x 640/960 находит объекты, ConvNeXt-small определяет по кропу один из 22 классов или `unknown`. В пакете:

- инструкция и `predict.py`;
- контрольные суммы весов;
- порог отклонения `unknown`.

Обоснование выбора — [`docs/Обоснование_моделей.pdf`](../../docs/Обоснование_моделей.pdf).

Веса (≈670 МБ) в git не хранятся, их даёт архив `jepa-models-2026-09-28.zip`. Целостность проверяется по `manifest.json` и `SHA256SUMS.txt`.

`apps/inference` пока настроен на предыдущую пару весов: у неё другие SHA-256, 22 класса без `unknown` и порог 0.5. Сервис нужно перевести на этот пакет.

# СтройКонтур — запуск демонстрации

## Быстрый запуск

Для просмотра готового прототипа нужен только Python 3. Дополнительные библиотеки, Node.js, Docker и GPU не требуются.

### macOS

1. Распакуйте ZIP.
2. Откройте папку `СтройКонтур`.
3. Дважды нажмите `start_macos.command`.

Если macOS не разрешает первый запуск, откройте Terminal в этой папке и выполните:

```bash
chmod +x start_macos.command
./start_macos.command
```

### Windows

1. Распакуйте ZIP.
2. Дважды нажмите `start_windows.bat`.
3. Если команда `py` отсутствует, установите Python 3 с сайта python.org и включите опцию `Add Python to PATH`.

### Linux

```bash
chmod +x start_linux.sh
./start_linux.sh
```

### Универсальный способ

Из корня распакованной папки:

```bash
python3 serve.py
```

На Windows также можно использовать:

```bat
py -3 serve.py
```

Сервис откроется по адресу `http://127.0.0.1:4173`. Для остановки нажмите `Ctrl+C` в окне терминала.

Если порт занят:

```bash
python3 serve.py --port 8080
```

## Что можно показать

1. На странице **Контроль** выберите камеру и переключайте кадры центральными стрелками.
2. Наведите курсор на жёлтый или красный bbox, чтобы увидеть основание предупреждения.
3. Справа сравниваются количества на выбранном кадре, по всей площадке и требования текущего календарного этапа.
4. На странице **План работ** меняйте длительность, последовательность и состав этапов. Даты и отставание пересчитываются автоматически.
5. На странице **Карта зон** выберите камеру, создайте многоугольник и задайте один или несколько запрещённых классов техники.
6. В строке зоны показывается процент читаемой видимости на выбранном кадре.
7. Через колокольчик или карточку **Готовность по проекту** загрузите JPG/PNG проектного вида. Для сравнения лучше использовать ракурс, близкий к камере.
8. Кнопка **Скачать отчёт** экспортирует JSON с планом, техникой, предупреждениями, зонами, видимостью и оценкой готовности.

Настройки плана, зоны и проектный вид сохраняются локально в браузере этого компьютера.

## Что уже находится в архиве

- `dist/` — полностью собранный сайт, изображения, bbox и результаты локального VLM;
- `mapping/` — сопоставление 377 строк графика с 14 классами техники, таблицы `required / required_any / optional`, регулярки и тесты;
- `scripts/` — подготовка данных, трекинг, image matching и локальный запуск SmolVLM;
- `tests/` — тесты геометрии и мультикамерного объединения;
- `docs/` — официальное техническое задание и таблица сопоставления;
- `README.md` — подробное описание архитектуры, алгоритмов и ограничений.

## Проверка алгоритмов

Тесты геометрии требуют Deno:

```bash
deno test --allow-read tests/geo-tracking.test.js
```

Тесты сопоставления этапов требуют Python и `openpyxl`:

```bash
python3 -m pip install openpyxl
cd mapping
python3 -m unittest test_stage_equipment_mapper.py
```

Для обычного запуска сайта устанавливать эти зависимости не нужно.

## Важные ограничения демонстрации

- Bbox взяты из реальных YOLO-аннотаций датасетов; обученная модель команды подключается вместо них без изменения интерфейса.
- Временная шкала коротких серий нормализована для демонстрации.
- Оценка готовности по изображению является предварительной визуальной оценкой, а не BIM-приёмкой объёмов.
- Процент видимости показывает читаемую часть полигона в выбранном ракурсе. Межкамерное покрытие в метрах требует полной калибровки камер и генплана.

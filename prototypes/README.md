# Прототипы

`stroykontur-v22/` — первый MVP команды «СтройКонтур» (26.09.2026), статический пульт мультикамерного контроля: выбор камер, история кадров, этап по составу техники, план и отставание, запретные зоны, простой по треку, межкамерная геометрия, проектный вид. Его функции переносятся в `apps/web`. Запуск: `python3 serve.py` в каталоге прототипа → `http://127.0.0.1:4173`.

Ограничения данных прототипа:
- рамки взяты из разметки датасетов `nickpudovkin/const-video-v2i-yolo26` и `nickpudovkin/dataset-object-identication-training-construction`, а не из модели;
- 6 из 11 кадров истории этапов синтетические: PNG техники наложены на реальные кадры, у рамок стоит пометка `synthetic`;
- SmolVLM-256M на всех 22 кадрах вернул один и тот же код `WORK_FRONT`;
- ТЗ и xlsx организаторов в репозиторий не входят. Для пересборки `mapping/` положите xlsx в `mapping/`.

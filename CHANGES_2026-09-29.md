# Изменения 29.09 поверх SiteWatch_team_demo_2026-09-29

Архив содержит только код. Папку `models/` и файл `.env.demo` возьмите из своего архива: веса и ключ не менялись.

## Что исправлено

- **Архив запусков не сохранялся.** Svelte-прокси нельзя положить в IndexedDB (DataCloneError), а ошибка глушилась. Теперь сохраняются снимки через `$state.snapshot`, кадры пишутся по одному.
- **Сайт по `http://IP:порт` без HTTPS.** Браузер не даёт там `crypto.randomUUID` и `crypto.subtle`, поэтому добавлены запасные реализации (`src/lib/browser-crypto.ts`, SHA-256 сверен с Node).
- **Описание работ:**
  - промпт больше не отвечает «Не определить по кадру» на очевидных сценах;
  - появилось поле «уверенность»;
  - запрос уходит через 0,7 с после выбора кадра, начатые запросы не рвутся и кэшируются;
  - «Повторить» повторяет тот же запрос.
- **Проверка по плану:**
  - стёртые числовые поля больше не считаются нулём;
  - коды зоны и этапа обрезаются;
  - при ручном добавлении кадра сразу проверяется шаг 1–60 минут;
  - в сервис правил уходят только учитываемые детекции.
- **Загрузка папки:** `.DS_Store` и другие файлы, кроме изображений, отбрасываются, кадры сортируются по имени. Поле выбора сбрасывается, чтобы ту же папку можно было выбрать повторно.
- **Архив (демо):**
  - дублирующиеся ключи списка сигналов (две машины одного класса в зоне) роняли страницу;
  - скачивание отчёта в Safari.
- **Сообщения об ошибках:**
  - ошибки сервиса правил и распознавания теперь по-русски;
  - прокси `/api/model/evaluate` понимает ответ, который не JSON;
  - лимиты длины в Rust считаются в символах, а не байтах.

  - лента сцен с карточкой «Свои кадры»;
  - панель запуска: кадры, режим «Стандартный / Детальный» (YOLO 640 / 960), кнопка «Распознать»;

## Деплой

- **Пересборка.** Нужно пересобрать веб, `sitewatch-deviations` (изменились тексты и лимиты) и inference (изменились сообщения об ошибках).
- **`ORIGIN`** должен совпадать с адресом, который открывает жюри (например, `http://IP:порт`). Иначе POST-запросы получат 403.
- **Ссылка для жюри.** Задайте `SITEWATCH_SHARE_TOKEN` (48+ символов), ссылка будет вида `/app/model?access=…`. `SITEWATCH_SHARE_TTL_HOURS` (новая переменная, по умолчанию 8) задаёт срок действия входа, для жюри удобно 336.
- **`.env.demo` с ключом модели описания не отдавайте жюри и не кладите в публичный репозиторий.**
- **На vast.ai Docker внутри инстанса не запускается.** Для такого случая есть скрипты `deploy/vast/*`: сборка без Docker под supervisord.
